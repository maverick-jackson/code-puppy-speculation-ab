The code mode journey

Every build of code mode we measured, per model: accuracy against cost or speed. Each path starts at code mode off and follows each change until today.

code mode off (before, and today) a code-mode build along the way #1015 as merged (today, labelled) + smart grep (tried, not adopted) Up and left is better. Hover a point for its numbers; double-click a model to see its steps labelled.
  1. Code mode off: the starting point (the same model without code mode).
  2. Before #1013: code mode as first shipped (sol and luna only; the other models were added later).
  3. After #1013 + #1014: batching guidance, and sub-agents called from code mode.
  4. Hill climb v1 to v3: shorter guidance; then the agent ID and workspace path moved out of the cached prompt (the big step for Claude); then guidance fixes (Opus, Sonnet and luna only).
  5. #1015 as merged: today's main, plus grep results typed as never empty.

Each point is the average over all 30 tasks, each task counted once, from 60 to 120 runs. Cost is API list price. Accuracy is the share of tasks fully right. Points from different batches carry run-to-run noise of a few percent. Per-model tables: summary; everything else: full report.
