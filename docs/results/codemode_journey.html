The code mode journey

How much more (or less) code mode costs than leaving it off, after each change we made. Zero is break-even; below the line, code mode wins.

Each point compares code mode with code mode off on the same build (today's build for "#1015 today"), averaged over all 30 tasks with each task counted once, from 60 to 120 runs per point. Cost is API list price. Changes inside the grey band are noise. Lines start where a model was first measured: sol and luna at first ship; the others at #1013 + #1014; Haiku and Astra skipped the v1 to v3 hill climb (dotted where a model skipped steps). The self-hosted glm53 and qwen3.8-27b were only measured today, so they appear on the final scoreboard, not here. Hover a point for the raw numbers.
