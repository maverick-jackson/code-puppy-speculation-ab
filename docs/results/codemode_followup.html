Code mode cuts model round trips in most workloads: a request does 1.0 to 4.8 tool calls instead of 1.0 to 1.9. Whether that becomes less wall time and fewer tokens depends on the model: a typical code-mode request carries 3.0k more input tokens than a plain one (median across models and workloads; the run_code description with every sandbox function signature, plus larger snippet results). In 2 of 30 model-workload cells it is smaller instead, because fewer turns resend less history. Faster with no more input tokens, median over tasks: gpt-6.1-sol, claude-haiku-5.5.
